# Jesus Saves Today - Multi-Region Shopee & Dynamic Category Bio Link Hub

Sistem website bio-link & multi-affiliate e-commerce mewah yang dirancang khusus untuk pengikut Facebook **Jesus Saves Today** (60k+ followers) dengan **Dynamic Regional Sub-Branches (Shopee ID, Shopee MX, Shopee PH, dll.) & Dynamic Category Manager**.

## Fitur Baru:
1. **Multi-Region E-Commerce Sub-Branches**: Anda bisa menambahkan cabang marketplace regional seperti `Shopee ID`, `Shopee MX`, `Shopee PH`, `Shopee BR`, `Amazon US`, dll. langsung dari halaman Admin tanpa menyentuh kode.
2. **Dynamic Categories Manager**: Tambahkan kategori produk baru sesuai keinginan Anda langsung dari Admin.
3. **100% Visual Theme & Branding Manager**: Preset warna tema instan (*Royal Gold, Emerald Diamond, Midnight Sapphire, Pure Ivory*) serta penggantian nama brand/judul toko secara dinamis.
4. **Full Clickable Product Cards**: Foto produk, Nama/Judul, dan Tombol Checkout otomatis terhubung ke link Involve Asia.
5. **Hidden Admin CMS (15 Klik Pemicu)**: Klik logo header 15 kali cepat (atau ketik `?admin=true` di URL) untuk masuk ke Admin.
