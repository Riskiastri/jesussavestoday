# Jesus Saves Today - Complete No-Code Admin Bio Link & Multi-Affiliate Hub

Sistem website bio-link dan multi-affiliate e-commerce mewah yang dirancang khusus untuk pengikut Facebook **Jesus Saves Today** (60k+ followers) dengan **Dynamic Platform Management via Admin & Full Clickable Product Cards**.

## Fitur Baru Tanpa Edit Kode (No-Code Admin):
1. **Dynamic Platform Manager**: Anda bisa menambahkan marketplace/platform e-commerce baru (seperti TikTok Shop, Tokopedia, Blibli, dll) langsung dari dalam Dashboard Admin tanpa perlu menyentuh kode HTML/JS. Platform baru tersebut akan otomatis muncul di opsi produk & tombol filter toko!
2. **Full Clickable Product Cards**: Foto produk, Nama/Judul Produk, dan Tombol Checkout semuanya terhubung otomatis ke link affiliate Involve Asia Anda.
3. **Hidden Admin CMS (15 Klik Pemicu)**: Cukup klik logo di pojok kiri atas 15 kali cepat (atau ketik `?admin=true` di URL) untuk membuka dashboard admin rahasia.
